2. A sua chave

Cole a chave que recebeu. Fica só neste browser e é usada para gerar os links e o código abaixo.

Novo (27/11/2026): 3 colunas no PAP

O product_availability_price passou a ter Stock Transaction No. of Facings, Stock Transaction Units available e Stock Transaction Packs available (Novembro em diante; Setembro e Outubro ficam vazios). Se o Power BI já está ligado, só é preciso trocar a consulta do PAP:

  1. Power BI Desktop → Base → Transformar dados (abre o Editor do Power Query).
  2. À esquerda, clique na consulta product_availability_price → Base → Editor avançado.
  3. Apague tudo e cole o bloco product_availability_price do ponto 3 (botão Copiar) → Concluído.
  4. Fechar e aplicar. As 3 colunas aparecem no fim da tabela: Facings e Units available como número inteiro, Packs available como número decimal.

65 leituras de Units available têm só "." escrito pelo auditor: no Power BI ficam vazias (em vez de erro). Os dados da API não são alterados.

3. Ligar o Power BI Desktop (passo a passo)

  1. Abra o Power BI Desktop → Relatório em branco.
  2. Base → Obter dados → Consulta em branco. Abre o Editor do Power Query.
  3. Em cada bloco abaixo: Nova origem → Consulta em branco → Editor avançado → apagar tudo → colar só esse bloco → Concluído → mudar o nome da consulta (à direita, em Nome) para o nome indicado no bloco. Os nomes têm de ser exactamente iguais (maiúsculas contam).
  4. Quando aparecer o aviso amarelo de credenciais: Editar credenciais → Anónimo → nível: o endereço mais curto → Ligar.
  5. Se perguntar níveis de privacidade: escolha Organizacional (ou Ignorar).
  6. Fechar e aplicar. O PAP é a maior tabela (cerca de 18 páginas) e demora cerca de 1–2 minutos.
  7. Relações (vista Modelo) — apague as que o Power BI criou sozinho e crie estas:
    DeParaCardinalidadeActiva
    survey_feedback[store_nu]demographics[store_nu]Muitos para umSim
    product_availability_price[visit_nu]survey_visit_db[visit_nu]Muitos para umSim
    demographics[visit_nu]survey_visit_db[visit_nu]Um para umSim
    product_availability_price[store_nu]demographics[store_nu]Muitos para umNão
  8. Confira o número de linhas de cada tabela (vista Tabela, em baixo à esquerda) com a coluna Linhas do ponto 1.
  9. Dados novos: basta carregar em Actualizar.

4. Power BI online (app.powerbi.com)

  1. No Power BI Desktop: Publicar → escolher o workspace.
  2. Em app.powerbi.com: abrir o workspace → no modelo semântico: ⋯ → Definições.
  3. Credenciais da origem de dados → Editar credenciais → Método de autenticação Anónimo, nível de privacidade Organizacional → Iniciar sessão.
  4. Actualização agendada → Ligado → escolher as horas → Aplicar. Não é preciso gateway.

5. A API (para quem programa)

PedidoDevolve
GET /api/estadoJSON público: tabelas, linhas, páginas, colunas, linhas por mês, data dos dados, hora da última actualização.
GET /api/dados?tabela=<tabela>&pagina=<n>&chave=<chave>CSV UTF-8 (vírgula, decimal com ponto, datas AAAA-MM-DD) com cabeçalho e até 10 000 linhas. Páginas a partir de 1. A chave também pode ir no cabeçalho x-api-key.

Tabelas: demographics, survey_visit_db, survey_feedback, product_availability_price, visibility_quality. Juntam todos os meses (coluna survey_number = AAAAMM).
